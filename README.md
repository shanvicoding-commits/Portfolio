# Shanvi Agarwal – Portfolio

A scroll-driven, parallax portfolio built with plain HTML, CSS and JavaScript. No build step, no dependencies.

## Files
- `index.html` – content and structure
- `style.css` – all styling (dark and light themes follow the visitor's system)
- `script.js` – scroll scene, animations and the copy-email button

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Publish on GitHub Pages
1. Create a new repository on GitHub (for example `portfolio`), set to Public.
2. Upload all files in this folder to the repository root (`index.html` must be at the top level).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and the `/ (root)` folder, then **Save**.
5. After about a minute your site is live at `https://<your-username>.github.io/<repo-name>/`.

Tip: name the repository `<your-username>.github.io` to get the shorter address `https://<your-username>.github.io/`.

## Edit your content
All text is in `index.html`. Search for the section ids `s1` to `s6` to update About, Vision, Skills, Projects, Beyond Academics and Contact.
